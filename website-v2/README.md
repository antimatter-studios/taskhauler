# Taskhauler — Marketing Site

A standalone Vite + React + Tailwind site for the Taskhauler project.

## Run locally

```bash
cd marketing-site
npm install
npm run dev
```

Then open http://localhost:5173.

## Build for production

```bash
npm run build
npm run preview
```

The built site lands in `dist/` and is fully static — drop it on any static host (Vercel, Netlify, Cloudflare Pages, S3+CloudFront, GitHub Pages).

## Editing

Each section is its own file under `src/sections/`. They're intentionally small (50–200 lines) so you can change copy, swap screenshots, or rewrite the layout without grepping a monolith.

Brand tokens (colors, fonts, animation timings) live in `tailwind.config.js` and one small CSS layer in `src/index.css`. Most styling is Tailwind utilities.

## Notes

- All screenshots are placeholder 1600×1200 captures sourced from `design_handoff_taskhauler/screenshots/`. Replace them with crisper captures generated by `design_handoff_taskhauler/prototype/capture.html` when you have time.
- The site uses `base: './'` in vite.config.js so it deploys cleanly as a static site to any subpath.
- Fonts are loaded from Google Fonts (Inter, Instrument Serif, JetBrains Mono). If you self-host them, drop the `<link>` tags in `index.html` and switch the references in `tailwind.config.js`.
